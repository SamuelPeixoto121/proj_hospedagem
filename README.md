\# proj\_hospedagem



Site estático de hospedagem feito com HTML, CSS e JavaScript puro.



\## Estrutura



\- `ARQUIVOS/index.html`: página principal

\- `ARQUIVOS/css/style.css`: estilos

\- `ARQUIVOS/js/app.js`: comportamento da página



\## Como visualizar



Abra o arquivo `ARQUIVOS/index.html` no navegador. Não é preciso instalar nada.
